How to print a personal allergy summary with AllergyFolio

Review recorded reactions, severity and verification fields, choose whether to include medications, and check the print preview before saving a personal copy.

By the AllergyFolio project · Published September 9, 2026 · Software guide

On this page

  1. Review the identity and recorded entries
  2. Decide whether medication names belong on this copy
  3. Use the browser’s print controls
  4. Label the copy for what it is
  5. Questions about this guide

Review the identity and recorded entries

The summary starts with the name from the authorized record. Check that it is the intended record before making a copy. For each allergy entry, read the label, recorded reaction, source severity, status and verification information. Missing fields are displayed as not supplied.

Decide whether medication names belong on this copy

The optional medication checkbox adds recorded medication names to the summary. It does not turn the page into a full medication review or add detailed directions. Choose the option according to the purpose of the personal copy you are making.

  1. Check the displayed identity.
  2. Read every included allergy entry and its source context.
  3. Choose whether to include recorded medication names.
  4. Open the browser print preview and check that the text is readable.

Use the browser’s print controls

“Print my summary” opens the browser print dialog. Paper size, margins, page breaks and saving as PDF are handled there. Inspect the preview before printing or saving, especially when the record contains several entries.

Label the copy for what it is

AllergyFolio produces a personal summary, not a verified emergency ID or a clinical certificate. An empty returned list does not establish that someone has no allergies. The copy does not update itself; compare it with the appropriate current source when you next use it. Live imports remain subject to production activation.

Questions about this guide

Does the medication option include doses?

The optional section lists recorded medication names. It is not a complete directions or prescription report.

Can AllergyFolio certify my allergy information?

No. It formats returned source information for personal review and printing.
